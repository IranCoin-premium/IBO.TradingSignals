## 2. Invariants & Control Plane Guardrails

1. **Human Authority Paramount:** The Human Administrator/CEO is the ultimate authority. Chief Agent and all specialist agents remain governed coordinators.
2. **Consequential Action Preview:** Any impactful mutation must provide:
   - Target resource and scope
   - Execution mode & environment
   - Risk Class ($R0-R4$)
   - Rollback plan
   - Verification criteria
   - Expiration TTL (stale approvals are invalidated)
3. **Governed Break-Glass Session:** Emergency access allows temporary elevation ($R4$) with mandatory justification, strict duration (default max 30 mins), and full auditable logging of all actions taken.
4. **Command Hub Centers:**
   - **Executive Dashboard:** Cross-system golden signals, costs, active incidents, and safe mode state.
   - **Task & Agent Center:** 24/7 worker queues, capability routing, and quarantine management.
   - **Incident & Resilience Center:** SEV 1-4 lifecycles, circuit breakers, and bounded recovery loops.
   - **Quality & Release Center:** Evidence-backed scorecard with independent verifier gate.
   - **Security & Secret Center:** Zero-trust policy evaluations, secret redactions, and access audits.
